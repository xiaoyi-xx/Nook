# Nook 首页

一个功能强大的个人首页，支持收藏常用网站、使用搜索引擎、链接静态页面，以及自定义背景图片。

## 功能特性

- **网站收藏管理**：添加、编辑、删除收藏的网站，支持自定义图标
- **搜索引擎集成**：内置Bing搜索引擎
- **静态页面链接**：自动扫描并显示static文件夹中的静态页面
- **自动获取网页图标**：添加网站时自动尝试获取favicon
- **响应式设计**：适配不同屏幕尺寸
- **深色模式支持**：可切换深色/浅色主题
- **背景图片设置**：支持设置背景图片，包括本地图片和URL
- **模态框虚化效果**：打开模态框时背景元素虚化

## 项目结构

```
Nook/
```

## 快速开始

1. **克隆项目**
   ```bash
   git clone <repository-url>
   cd Nook
   ```

2. **启动本地服务器**
   可以使用任何本地服务器，例如：
   - VS Code Live Server
   - Python 内置服务器：`python -m http.server 8000`
   - Node.js http-server：`npx http-server -p 8000`

3. **访问首页**
   打开浏览器，访问 `http://localhost:8000`

## 使用方法

### 添加收藏网站
1. 点击「添加」按钮
2. 填写网站名称和URL
3. 选择图标类型（表情图标或URL图标）
4. 点击「保存」按钮

### 添加静态页面
1. 将静态HTML文件放入 `static` 文件夹
2. 编辑 `static/pages.json` 文件，添加新的页面路径
3. 刷新首页，新的静态页面会自动显示

### 设置背景图片
1. 点击左上角的三条横线按钮打开设置面板
2. 在「背景图片」输入框中输入图片URL，或点击文件选择器选择本地图片
3. 点击「应用」按钮

### 切换主题
点击右上角的🌙/☀️按钮切换深色/浅色主题

## 注意事项

- **静态页面管理**：静态页面列表通过 `static/pages.json` 文件管理，添加或删除静态页面时需要编辑此文件
- **本地文件系统**：直接打开HTML文件（file://协议）时，由于浏览器安全限制，静态页面列表会使用硬编码的默认值
- **服务器部署**：部署到服务器后，静态页面会自动从 `static/pages.json` 文件加载

## 自定义

### 修改默认背景图片
编辑 `script.js` 文件中的 `loadSettings` 函数，修改默认背景图片URL

### 添加搜索引擎
编辑 `script.js` 文件中的 `searchEngines` 对象，添加新的搜索引擎

### 修改静态页面默认图标
编辑 `scanStaticPages` 函数，修改默认图标设置
