# Nook

一个功能强大的个人浏览器首页，收藏常用网站、管理工具快捷入口，支持自定义背景和深色模式。

## 功能特性

- **网站收藏管理** — 添加、编辑、删除收藏的网站，支持 emoji / URL 自定义图标
- **自动获取网站图标** — 智能检测 12 种常见 favicon 路径，自动填入
- **长按拖拽排序** — 按住卡片拖到目标位置，松手自动保存新顺序
- **横向分页导航** — 收藏和工具每页 6 项，翻页按钮 + 圆点指示器，支持点击圆点跳转
- **搜索引擎集成** — 内置 Bing 搜索，带搜索历史记录
- **静态页面聚合** — 自动扫描 `static/` 目录，自动读取页面标题
- **深色模式** — 一键切换深色/浅色主题，独立存储
- **背景图片** — 支持 URL 或本地上传，毛玻璃半透明效果
- **响应式设计** — 适配桌面端和移动端
- **本地存储** — 收藏数据、设置、主题偏好全部保存在浏览器 localStorage

## 快速开始

```bash
# 克隆
git clone https://github.com/xiaoyi-xx/Nook.git
cd Nook

# 启动本地服务器（任选其一）
npx http-server -p 8000
# 或
python -m http.server 8000
# 或使用 VS Code Live Server 插件

# 打开浏览器访问
open http://localhost:8000
```

## 用法

### 收藏网站

1. 点击「+ 添加」卡片
2. 输入网站名称和地址
3. 选择图标类型：
   - **表情图标** — 从常用图标列表点选，或手动输入
   - **URL图标** — 切换到 URL 模式后，焦点离开网址输入框自动检测 favicon
4. 点击「保存」
5. 长按已有卡片可拖拽调整顺序

### 管理工具页面

将 HTML 文件放入 `static/` 文件夹，然后在 `static/pages.json` 中注册路径即可自动出现在「我的工具」区域。

### 分页导航

- 收藏和工具每页最多展示 6 项
- 超出自动分页，底部出现 `‹ ›` 翻页按钮和圆点指示器
- 点击圆点直接跳转到对应页

### 背景与主题

| 操作 | 方式 |
|---|---|
| 设置背景图 | 左上角 `☰` → 背景图片 → 输入 URL 或选择本地图片 → 应用 |
| 深色/浅色切换 | 右上角 `🌙` / `☀️` 按钮 |
| 数据存储 | 全部自动保存在浏览器 localStorage，刷新不丢失 |

## 技术栈

- HTML5
- CSS3（Flexbox / Grid / backdrop-filter 毛玻璃）
- JavaScript（原生 ES6+，无框架依赖）
- localStorage（持久化存储）
- HTML5 Drag & Drop API + Touch Events（拖拽排序）

## 注意事项

- **本地文件协议**：直接双击打开 `index.html`（`file://` 协议）时，浏览器的 CORS 限制会导致 `pages.json` 无法加载，此时会使用默认的静态页面列表
- **服务器部署**：部署到 HTTP 服务器后，所有功能正常工作
- **favicon 检测**：由于浏览器的跨域限制，自动获取 favicon 采用 Image 对象逐一尝试常见路径的方式，部分自定义路径的图标可能无法检测到
- **图标尺寸**：所有图标统一缩放到 40×40px 显示，大图自动适应
